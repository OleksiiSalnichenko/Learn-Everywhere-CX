# 0003. Онлайн-переклад через Firebase AI Logic

## Контекст
Переклад має визначати мову, повертати до двох відповідників і речення, не переносячи словники користувача до хмари.

## Рішення
Переклад виконує Gemini `gemini-3.5-flash-lite` через Firebase AI Logic на Spark без Cloud Billing, зі структурованою JSON-схемою та App Check. Єдиний `TranslationProvider` ізолює сервіс, а незалежний валідатор перевіряє мови, обов’язкові поля, кількість значень і довжини; низька впевненість веде до вибору користувача, а не до автоматичного запису.

## Чому
Відхилено офлайн-модель: для неї окремо треба довести ліцензії, розмір і якість двох мовних напрямків та речень. Відхилено прямий API із сервісним ключем у APK, бо секрет неможливо надійно приховати в мобільному клієнті; відхилено автоматичний перехід на платну модель, бо погоджено Spark без billing.

## Наслідки
Провайдера й назву моделі можна змінювати за межею контракту, словники лишаються локальними, а невалідна відповідь не стає записом. Мінуси: додавання слова залежить від мережі, квоти, Firebase-конфігурації та App Check; недоступність моделі дає помилку й ручний Retry, без прихованого fallback.
