# План — чернетка до завершення G2

T2: 6 змістовних тасків. Цей файл ще не публікує завершений план: вибір режиму перекладу може змінити інтеграційний таск.

| Таск | Результат | Залежності | Зона |
|---|---|---|---|
| 01 | Android-застосунок запускається; погоджена тема, навігація, локальні словники й дефолтовий вибір | — | Gradle, app shell, data, library |
| 02 | Створення/перейменування/редагування/видалення і безпечний JSON-обмін із UI | 01 | library, transfer |
| 03 | Голосове/текстове додавання через узгоджений провайдер, мови, preview і OK/Cancel | 01 | intake, home, translation |
| 04 | Повні налаштування, три мови UI, світла/темна тема і точний план аудіопослідовності | 02,03 | settings, localization, playback plan |
| 05 | Фонове програвання, TTS-кеш, media controls, картка й екран блокування | 04 | playback, service |
| 06 | Повна перевірка користувацьких сценаріїв, доступність, міграції, фінальний APK та документація | 05 | integration, tests, docs |

02 і 03 можуть виконуватися паралельно після стабілізації контрактів у 01. Інші кроки послідовні, бо використовують інтегрований UI і ресурси. Детальні критерії беруться зі spec.md; файл таску створюється лише після закриття G2.
